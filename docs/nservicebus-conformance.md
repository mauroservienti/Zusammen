# NServiceBus TransactionalSession Conformance

Maps every test in the [NServiceBus TransactionalSession acceptance tests](https://github.com/Particular/NServiceBus.TransactionalSession/tree/main/src/NServiceBus.TransactionalSession.AcceptanceTests) to a Zusammen test, or explains why it does not apply. A scheduled CI job fails when an upstream `When_*.cs` file is missing from this table.

Status: ✅ covered · ⏸ deferred · ❌ not applicable

| Upstream test                                                          | Scenario                                                | Status | Zusammen                                                                                                |
| ---------------------------------------------------------------------- | ------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------- |
| `When_outbox_commits_after_control_message`                            | Commit slower than the commit window                    | ✅     | Tombstone stored, commit throws `SessionCommitConflictError`, nothing dispatched                        |
| `When_outbox_commits_after_receiving_control_message`                  | Control message arrives before commit                   | ✅     | Delayed retries until the record appears, all messages dispatched                                       |
| `When_outbox_entry_becomes_visible_after_tx_timeout`                   | Committed record not yet visible to the control handler | ✅     | Control path reads with primary / `majority` concerns; storage-lag scenario tested with a fake provider |
| `When_using_outbox_and_send_to_another_endpoint`                       | Send on commit                                          | ✅     | Happy path                                                                                              |
| `When_using_outbox_and_send_local`                                     | Send on commit                                          | ✅     | Happy path (no "local" concept; send to own queue is a regular send)                                    |
| `When_using_outbox_and_send_local`                                     | Not committed → nothing sent                            | ✅     | Rollback                                                                                                |
| `When_using_outbox_and_send_local`                                     | Nothing sent → no control message                       | ✅     | Empty session                                                                                           |
| `When_using_outbox_and_send_local`                                     | Immediate dispatch even if not committed                | ⏸      | Deferred: not in the initial scope; no `immediateDispatch` option                                       |
| `When_using_outbox_and_send_local`                                     | Ambient transactions flow                               | ❌     | .NET `TransactionScope`-specific                                                                        |
| `When_multiple_endpoints_use_transactional_session`                    | Independent commit / rollback across endpoints          | ✅     | Two factories with separate control queues in one process                                               |
| `When_using_outbox_send_only`                                          | Send-only endpoint with processor endpoint              | ❌     | No separate processor role: every factory processes its own control queue                               |
| `When_using_outbox_send_only_and_receiver_is_the_processor`            | Processor is the message receiver                       | ❌     | No separate processor role                                                                              |
| `When_send_only_endpoint_uses_processor_without_transactional_session` | Misconfigured processor                                 | ❌     | No separate processor role; the equivalent misuse (`open()` before `start()`) throws                    |

| `When_not_using_outbox_send_only`                                      | Transactional session without outbox, send-only         | ❌     | Zusammen always uses the outbox                                                                         |
| `When_using_outbox_and_audit_enabled`                                  | Control message not audited                             | ❌     | No audit concept; control messages live on a dedicated queue and never reach business consumers         |
| `When_using_endpoint_logging_scope`                                    | Logging scope enrichment                                | ❌     | NServiceBus logging internals                                                                           |
| `When_using_transactional_session`                                     | Same operation order as the core pipeline               | ❌     | NServiceBus pipeline internals                                                                          |
